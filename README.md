# 🌡️ Monitor de Temperatura e Umidade com ESP32 + ThingSpeak - PUC IOT MAIO/2025

O projeto utiliza um microcontrolador **ESP32** para monitorar a **temperatura** e **umidade** do ambiente com o uso de um sensor **DHT11**, além de enviar esses dados para a plataforma **ThingSpeak** via API.

Também possui um **relé** é controlado automaticamente caso a temperatura ou umidade alterem demais

## 🛠️ Componentes Utilizados

- ESP32
- Sensor DHT11
- Módulo Relé
- Acesso Wi-Fi
- Conta no [ThingSpeak]
